# Sprint demonstrations

The two captioned demonstrations were captured from the running portal on 16 November 2026 using disposable staff and student accounts and sample questions. They show retrospective walkthroughs of the sprint functionality.

| Video | Duration | Build and coverage |
|---|---:|---|
| [Sprint 1](Sprint_1_Demo.mp4) | 1:00 | Sprint 1 integration commit `0b7de7e`. Staff exam and question views, student navigation, answer persistence, confirmation and manual submission. |
| [Sprint 2](Sprint_2_Demo.mp4) | 2:00 | Main commit `41bc4aa`. Review flag and navigator state, saved answer, actual timer expiry, score withholding and staff release. The timer sequence cuts elapsed waiting time. The disposable exam window was closed after the timeout to demonstrate the real release control. |

The [original project demo](Project_Demo_Video.mp4) is also available. The [live demo run sheet](../docs/FINAL_DEMO.md) covers the presentation order and supporting evidence.
